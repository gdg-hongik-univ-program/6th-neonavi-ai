# 너네비(NeoNavi) 진행 상황 — 재개용 요약

> 최종 업데이트: 2026-07-11 · 세션 컴팩트 후 이 문서부터 읽고 이어가면 됨.

## 프로젝트 개요
- **너네비(NeoNavi)** — 성향 맞춤형 내비게이션. 출발지·목적지 입력 시 사용자 정보(나이·성별·동승자·차종·짐·연식)로 운전 성향을 **자동 추론**해, 거리도 합리적이면서 성향에 맞는 경로를 추천.
- GDG 프로젝트 트랙 (AI 트랙). 핵심 차별점 = "사용자가 모드를 고르는 게 아니라 시스템이 성향을 추론".
- 핵심 AI 기여 = 지도 API 좌표 + 공공데이터로 경로 특성(곡률·경사·연비·통행료·신호등)을 만드는 **Feature Engineering** + 성향 추론 모델.

## 확정된 결정사항
- **모델 방향**: 방안 A(약지도 weak supervision + **Two-Tower** 추천모델) 우선. 방안 B(퍼지/최적화/LLM 등 무학습)는 대안으로 열어둠.
- **플랫폼**: 모바일 우선(mobile-first) 반응형 웹.
- **스택**: React+Vite+TailwindCSS / Django+DRF / PyTorch / DB는 개발 sqlite→배포 PostgreSQL.
- **지도 API**: Kakao 잠정(무료 1만/일). Naver는 연료비 제공하는 대안. (최종 미확정)
- **실시간 GPS**: 풀 턴바이턴 내비 구현 안 함. 브라우저 **Geolocation API(watchPosition)** + 지도 SDK로 경량 주행 화면 처리. 풀 내비는 향후 확장. (Tmap/Kakao Navi SDK는 네이티브 전용이라 웹 부적합)
  - 상세 조사: [`네비게이션_기술조사.md`](./네비게이션_기술조사.md) — Lv1/Lv2/Lv3 난이도, 보간·Wake Lock 제약. **목표 Lv2(회전 안내 카드+남은거리), 리라우팅(Lv3)은 안 함.**
- **평가 방법**: 학습 라벨 없음 → 약지도로 학습, **인간 선호 설문(일치율)**으로 검증.
- **입력 스키마**: 나이(수치)·성별(남/여)·동승자(혼자/가족/노약자[반려동물 포함]/친구)·차종(세단/SUV/화물차/경차)·짐(0~100kg)·연식(0~10년).
- **성향 모드**: Comfort / Sports / Eco (각각 속도·편안함·연비·통행료회피 가중치 벡터).
- **라벨 데이터**: "인구통계→경로성향" 공개 라벨 없음 → 학술 근거(MDSI, Sato) 기반 규칙으로 약지도 합성.
